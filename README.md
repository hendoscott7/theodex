## Adding a work

Add an entry to the `WORKS` list near the bottom of `index.html`:

```js
{ name: "Name", line: "One short line.", url: "https://…", image: "img/name.jpg", updated: "2026-11-08T21:50" }
```

Put the still in `img/` (16:10 works best). Cards sort themselves by `updated`, newest first.
