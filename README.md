Live: https://hendoscott7.github.io/theodex/

## Adding a work

Add an entry to the `WORKS` list near the bottom of `index.html`. Works show top to bottom in list order:

```js
{ name: ["First line", "Second line"], color: "#96a46f", title: "Short\ntitle", text: "One line.\nAnother.", url: "https://…", image: "img/name.jpg", updated: "2026-11-09", icon: "<path d=…/>" }
```

Put the still in `img/` (16:10 works best). `name` can be one or two lines; `icon` is SVG paths on a 64×64 grid.
